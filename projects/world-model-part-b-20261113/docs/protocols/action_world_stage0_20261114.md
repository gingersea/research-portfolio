# 转向阶段0：动作条件状态预测与规划（运行前固定）

用户要求收尾后换方向，尚未指定新题目。本轮先做可逆、CPU级阶段0验证，暂按保留世界模型领域转向动作条件学习与规划；最终研究主题仍允许用户调整。这里训练线性状态转移基线，不把它包装为新的视觉基础世界模型。

研究问题：在同样状态观测、数据和预算下，显式动作输入的学习模型相对忽略动作模型，能否预测新的动作序列并支撑实际闭环控制？这是接口/基线可行性检验，没有新颖性或真实机器人性能主张。

世界：二维点质量，状态(x,y,vx,vy)，动作(ax,ay)每维[-1,1]，dt=.2，速度衰减.92。v_next=.92*v+.2*a；position_next=position+.2*v_next。无边界、碰撞、图像观测或噪声。状态和动作均完全可见；有意选择可识别的线性世界，未来视觉/部分可观测/变动力学必须另做实验。

训练：3个种子7/17/27，各256条轨迹×16步；初态位置均匀[-1,1]、速度[-.2,.2]。每步动作来自{(0,0),(1,0),(-1,0),(0,1),(0,-1)}，共享给两臂。action_conditioned以[state,action,1]拟合next_state，action_blind以[state,1]拟合next_state；普通最小二乘，没有根据测试结果调参。保存拟合系数及训练数据哈希。

测试：固定新seed20261114，各128条轨迹×30步；动作从四个对角动作(±1,±1)抽样，测试动作组合未直接出现在训练中。自回归 rollout，报告1/10/30步全状态RMSE、各训练种子的结果及范围。该组合外推在线性世界中预期很容易，不泛化到非线性动力学或视觉。

规划：固定seed20261115，64个初态/目标相同episode，目标位置初态加半径[.8,1.5]随机方向位移，初速为0。模型各使用同样horizon12、32次receding控制、动作代价.01、终态速度权重.25的线性最小二乘规划，动作每维裁剪[-1,1]。成功为最终位置距离<=.2世界单位。action_blind没有动作通道，B=0，规划自然不能通过动作影响其预测；该基线衡量动作接口的必要性，不是与复杂规划算法竞争。另报告已知真实A/B的oracle参考，明确其为非学习上界。

输出逐轨迹误差、逐episode轨迹与动作/成功、系数、协议/代码/数据哈希、软件版本和表格。64个episode是条件于固定世界的场景，不计算面向真实任务的成功率置信区间或P值。预期结果不作为验收条件，失败也完整保留。停止条件是全部固定矩阵、有效数值与约束核验通过、结果落盘；不靠改episode/阈值强行成功。

后续研究问题另行收紧为：在有像素观测、遮挡或未见动力学条件下，多步误差改善是否能转化为闭环任务成功，且失败时是否有可校准的拒绝/再观察策略。阶段0不验证这些假设。

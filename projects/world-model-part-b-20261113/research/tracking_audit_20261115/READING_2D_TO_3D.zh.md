# 从二维视频到三维运动：面向本项目的论文精读

阅读日期：2026-11-15。本轮重点不是选择一个“三维化按钮”，而是弄清哪些量来自图像、哪些量依赖先验、哪些量可以作为物理一致性的测量。以下四篇均阅读原始方法与实验；版本、原始 HTML、数学文本、图表说明保存在 `papers/` 与 `paper_sources*.json`。

阅读范围：CoTracker3 v1 正文及附录 A–D；SpatialTracker v1 正文（本地 HTML 没有单独补充材料，未把未读补充材料算作已读）；MegaSaM v2 正文与附录 A/B；TAPIP3D v3 正文与附录 A–H。MegaSaM/TAPIP3D 初次归档的 v1 另外保留，以下分析以已核实的 v2/v3 为准，不混用 TAPIP3D v1 的 Local Pair Attention 名称与 v3 的 N2N 名称。实际查看了 CoTracker3 图2、MegaSaM 图4、TAPIP3D 图2/3；SpatialTracker 图2的图片获取情况见 `artifacts/verification.json`，不能把图注阅读当作已经看过图片。未逐个播放各论文的补充视频，也未运行四套作者模型。

## 先分清三种任务

| 任务 | 输入→输出 | 对我们测量的意义 |
|---|---|---|
| 二维点/实例跟踪 | RGB 与初始查询→位置、可见性、置信度 | 先解决对象在不在、是否还是同一对象；不必先重建整个三维场景 |
| 相机与深度重建 | 视频→内参、相机位姿、逐帧深度/点图 | 把像素变成相机/世界坐标；还不能自动知道同一材料点去了哪里 |
| 动态三维轨迹 | RGB、深度、内外参和查询→三维轨迹及可见性 | 在深度可靠时可消除相机运动、利用三维邻域；预测的遮挡轨迹仍不是直接观测 |

把视频拟合成可渲染的动态场景还可以服务新视角合成，但“重投影看起来像”并不独自保证材料身份、度量尺度或运动参数正确。本研究需要先决定最终量是对象质心、表面点、落地时刻还是三维加速度，避免用一个能输出漂亮点云的方法代替测量定义。

## 1. CoTracker3：先解决对应与可见性

[Karaev 等，CoTracker3，arXiv:2410.11831v1](https://arxiv.org/html/2410.11831v1)。其关键不是按固定颜色找团块：查询附近和当前估计附近的多尺度特征构造 4D 相关，Transformer 联合更新位置、visibility 和 confidence。多点上下文帮助遮挡推断；offline 可用整段，online 使用滑窗。§3.2–3.3 将可见性与定位置信度分开。§4 的 cross-track 消融支持其贡献；附录 D 指出教师质量限制伪标注。附录 A 的真实视频筛选排除了 CGI/动画，因此不能默认本轮程序图像已被其真实数据训练覆盖。

我们应借鉴的是“持续查询身份 + 可见性/置信度分离”，不是把每个网络输出都计作观测。若输出位置 $(u,v)$、可见性 $v=0.1$、定位置信度 $c=0.9$，存在坐标不表示当前看到了对象。举例定义应用层可见观测分数 $s=vc=0.09$；即使在自设阈值 0.5 下拒绝它，也只能说明规则拒绝，不能证明该阈值已在我们的数据上校准。这个数值例子是教学用自设例，不是论文报告的实验。

点追踪器跟踪的是查询表面点。旋转球上的一点可能绕球心运动，不能直接把它当球心；多个可见点的均值也不必等于质心。后续若采用它，应以实例掩膜、轮廓/几何中心和多点对应交叉验证，记录可见性标签，而不是在遮挡时沿预测轨迹继续计算落地时间。

## 2. SpatialTracker：三维表示与刚性先验

[Xiao 等，SpatialTracker，arXiv:2404.04319v1](https://arxiv.org/html/2404.04319v1)。§3 将深度提升后的图像特征压到三张 triplane，并迭代更新轨迹；训练时以刚性 embedding 加权约束点对距离随时间不变。表5去掉 ARAP 后 DAVIS AJ 从 61.1 降到 55.1，支持它有贡献，不能据此声称去掉就完全失败。§3.5 在无内参时假设焦距等于图宽；§4 明确 RGB 模式主要评估二维投影，三维评估使用已知深度/内参。标题里的“三维”不等于任意 RGB 输入都有独立验证的米制轨迹。

ARAP 的核心可以用一个自设两点例子理解：同一物体上两点最初相距 0.10m，后来估计相距 0.15m，则距离保持残差为 0.05m。它能帮助定位遮挡点，也可能把真实生成变形拉回“像刚体”的解释。对我们的物理评估，刚体拟合可以提供假设，但必须同时保留图像残差与未正则化的形变证据；不能用刚性先验修好轨迹，再据此宣布视频保持刚性。

另一个实现要点是区分 camera-space 与 world-space：各帧的三维表示若处于各自相机坐标，观察到的位移仍混有相机运动。这不是加入一个深度通道就自然消失的问题。

## 3. MegaSaM：重建深度，也判断何时不可观测

[Li 等，MegaSaM，arXiv:2412.04463v2](https://arxiv.org/html/2412.04463v2)。§3 将学习的对应、运动权重与单目深度初始化放进可微 BA；之后固定相机再优化时序深度。§3.2.2/图4用 Hessian 近似分析可观测性，在低视差处加强先验约束。表5的初始化、运动模块、两阶段训练与 uncertainty-aware BA 消融显示各项有贡献。§4 的相机 Sim(3) 对齐、深度全局尺度/偏移对齐意味着成绩不能直接当作无标定的绝对尺度精度。附录 B 仍报告无可靠纹理、运动/相机共线等失败情形。

本项目固定相机、平坦背景正处于需要谨慎的情形。下面是通用针孔几何的独立推导：静态背景点在相机不动时满足 $p_j=p_i$，而

$$p_j=\pi\bigl(R_{ji}[D_iK^{-1}\tilde p_i]+t_{ji}\bigr).$$

当 $R_{ji}=I,t_{ji}=0$，投影会消掉 $D_i$，所以任意正深度都能给出相同像素。多加几百个完全相同视角并不能增加这项深度证据。学到的深度先验可给出一个答案，却不能被称为从该视频唯一恢复出的真值。动态对象也不能在未知非刚性运动下直接当作静态多视角三角化点。

因此目前首先应利用已知静态角标做二维相机/装置检查，避免让复杂重建系统在无视差输入中自由解释出额外相机平移。

## 4. TAPIP3D：稳定世界坐标中的邻域匹配

[Zhang 等，TAPIP3D，arXiv:2504.14717v3](https://arxiv.org/html/2504.14717v3)。§3 用外部深度/相机把特征提升到首帧相机定义的世界系，在三维 kNN 邻域之间做 N2N attention，随后迭代更新轨迹和可见性。表5支持 XYZ-world 与 N2N 的贡献，但依赖输入几何。表2及§5明确：可靠深度提升二维投影效果，估计深度差时也可能弱于二维跟踪。附录 G 的二维评估没有达到最新二维方法水平。附录 B 还用 GT track 最大深度构造归一化上界；无标注部署不能照搬这种可用信息假设。

可借鉴的是把相机运动与对象运动分开，而不是预先假设三维优于二维。本轮相机不动，坐标稳定化带来的额外收益未必大；最先缺的是可靠的持续身份、形状和深度证据。若背景/深度把两个球错误连成同一表面，3D kNN 也会选错邻居。

为理解世界系，设一个固定点 $X_w=(1.2,0.1,2)$m，相机中心第一帧 $C_0=(1,0,0)$、第二帧 $C_1=(1.1,0,0)$，旋转均为单位阵。相机坐标从 $(0.2,0.1,2)$ 变为 $(0.1,0.1,2)$；若 $f_x=500,c_x=384$，水平像素从 434 变到 409。物体并没有横向运动 25px 对应的世界位移；补回相机中心后，两帧都得到同一个 $X_w$。这是自设几何例子，不是论文实验。

## 从公式看，二维升三维到底缺什么

设相机内参 $K\in\mathbb R^{3\times3}$，像素齐次向量 $\tilde p=(u,v,1)^T$，深度 $D$ 以米计；世界到相机变换为 $X_c=R_{cw}X_w+t_{cw}$。则

$$X_c=DK^{-1}\tilde p,\qquad X_w=R_{cw}^{T}(X_c-t_{cw}).$$

自设例子：$f_x=f_y=500,c_x=384,c_y=256$，像素 $(434,281)$。取 $D=2$m，有 $K^{-1}\tilde p=(0.1,0.05,1)$，得到 $X_c=(0.2,0.1,2)$m；取 $D=4$m，则 $X_c=(0.4,0.2,4)$m。两者投影完全相同。未知 $D$ 时一个像素给的是一条射线，未知相机内外参时歧义更多。

整体公共尺度 $s$ 可在某些比值中抵消，例如 $h_L/h_R$；但每帧/每物体的不同深度尺度、偏移、视角变化不会自动抵消。若要从世界轨迹测 $g$，还需要尺度、时间标定、重力方向、质心定义和可靠可见性。当前只画了一条地面线，不能由此得到完整三维地平面和上述参数。

若新实验确实限制所有运动在同一标定平面，可以先考虑平面单应性或已知相机与平面的射线求交，成本更小、假设更明确。但本轮四个背景角标没有独立证明与球运动平面共面，不能把这个假设补写成已完成标定。

## 对下一阶段的方法选择

第一步应是二维测量验证：使用 CoTracker3 一类持续点对应作为候选，结合实例轮廓；在外观变化、同色、干扰、消失、遮挡、重新出现和身份交换控制上评估定位、可见性与 ID switch。预测点、当前可见轮廓和对象身份必须分开记录。

第二步才比较几何输入：已知深度/双目/标定平面作为可验证上界，单目视频深度作为待测条件。采用相同视频、查询、评估单位与阈值，先量化深度时序抖动和重投影误差，绝不把重建先验当真值。若二维足以稳定测同场景关系，就没有必要为使用三维而增加不确定性。

第三步才接物理关系：只使用观测支持的质心/接触时间；留出从未用于调参数的新控制与新初态。跟踪器的遮挡外推可以用于保持假设身份，不能充当新的可见落体样本。ARAP 或动力学先验若用于重建，必须另设未经这些先验修饰的物理失败指标。

本轮已经做的最小修正与失败挑战见 [诊断报告](REPORT.zh.md)。当前原型没有通过持续身份安全挑战，因此不升级成生产物理裁判。这里的方法路线是下一阶段建议，没有声称四套作者模型已运行或我们的三维问题已解决。

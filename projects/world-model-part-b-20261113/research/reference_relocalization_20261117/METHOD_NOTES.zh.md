# 本轮方法理解与验证边界

研究问题是：参考帧与目标帧的全局对应，能否真正补回持续跟踪丢失的正确位置，
同时控制错误接受？生成模型的物理错误不属于这轮优化对象。

PointSt3R 官方发布的 EgoPoints 评测代码对参考图、目标图联合推理，取得两张
稠密描述子图；在参考图按初始查询的亚像素位置双线性采样，再在整个目标图做
余弦最近邻。因此参考图描述子也依赖当前配对，不能只算一次参考图特征后通用于
所有目标。我们的适配器逐对重新推理，没有根据未来人工位置限制搜索窗口。
依据为保存的 `source_api/pointst3r_ego_points_eval.py` 与完整固定源码归档。

官方 PointSt3R 权重分享页匿名返回“链接已过期”，原始 HTML 已保存。因此实际
加载的是官方公开 MASt3R 静态预训练权重，而不是动态微调 PointSt3R。加载时
逐项检查 missing/unexpected keys，均为空。公开模型与源码链接：
[PointSt3R 发布](https://github.com/rhodriguerrier/PointSt3R)、
[MASt3R 模型卡](https://huggingface.co/naver/MASt3R_ViTLarge_BaseDecoder_512_catmlpdpt_metric)。
权重经作者公开 HTTPS 地址取得，保留 ETag、精确长度、每段哈希和整体 SHA256；
没有得到作者另行发布的该 PTH 文件校验和，不把本地哈希冒充发布方签名。

另外核对官方可见性实现：`mast3r/catmlp_dpt_head.py` 只有在输出模式包含 `+vis`
时才增加 `head_vis`，输出参考图每个像素的 `vis_in_other`。
`pointst3r_tapnet_eval.py` 对该输出取 sigmoid，再在参考查询位置取值、按0.5阈值
判断其在目标帧是否可见。它不是在已经找出的目标候选处读取一个“匹配很像”的分数。
这提供了一个重要的结构区别：可见性监督是在问“参考点是否出现在另一张图”，而
最近邻搜索是在被迫回答“目标图哪里最像”。当前 MASt3R checkpoint 输出模式仅为
`pts3d+desc24`，没有这套训练过的可见性头；随机增加一个头或用 conf/desc_conf
代替它都不构成该方法的复现。官方训练配置还包含动态对应采样和单独可见性损失，
所以静态基线的结果不能用于否定动态微调 PointSt3R。这里依据为固定官方源码，
没有声称本轮实际运行了这些缺失的权重或完成其训练。

全局搜索不依赖前一帧估计位置，具备跨大位移重新定位的结构条件；它也必然会在
目标不存在时找出一个“最像”的位置。raw 对照特意接受所有有限候选，使这种
强制对应的假接受进入分母，而不是当作已经解决了可见性。往返门将该候选的描述子
在参考图反向最近邻，要求回到初始查询的归一化距离严格小于4。这是同一对特征图
的自洽检查，没有独立的人工身份观察，也没有校准为可见概率。

开发结果体现了两者的区别：往返门能够拒绝已知出画点，却仍接受大量可见点的
错误位置。图中最严重的一个通过门的错误，参考查询在手与食材附近，人工目标点
已移动到锅边，描述子匹配却落在砧板附近。该实例可证明往返自洽不足以保证对应
正确；它不能单独证明错误的训练机制，更不能被当作真实视频违反物理规律。

本轮补充配对核算，将“原生坐标已正确、但原生可见性拒绝”与“原生坐标确实错、
新方法坐标正确”分开。旧开发集16次标注重现中，原生与 MASt3R 都定位正确15次；
MASt3R 新增接受的3次均属于前一种，新增正确重现坐标为0。其余可见点存在10个
MASt3R 独有正确位置，同时丢掉35个原生独有正确位置，净减少25个正确位置。
这些是旧样本的描述性诊断，不是新验证结论，也未据此调整模型或阈值。

当前比较有以下明确边界：

- 输入同为既有流程生成的512×288 RGB，原始 JPEG 经 OpenCV INTER_LINEAR
  转换；作者示例直接对原图用 PIL LANCZOS，默认高度384。本轮固定高度288并沿用
  相同派生输入，属于适配比较，不能称原论文官方排行榜复现。
- 误差按 x×256/W、y×256/H 归一化，欧氏距离严格小于4。它不是原始图上的4像素。
  人工标签只在少数时刻已知，未知帧不作为遮挡或负例；无法据此验证逐帧完整身份。
- native 是离线完整视频 CoTracker3；MASt3R 是参考—目标图像对。二者均为本地
  冻结推理，没有训练、未来人工查询重置、真值深度或新验证集调参。
- 新参与者与旧开发参与者隔离；这只保证本项目开发/新验证的分离，没有证明模型
  原始预训练数据与这些参与者完全隔离。重现富集、小样本和归档前缀选择也限制外推。
- 本轮只使用 MASt3R 描述子。模型带三维预测头不等于本轮验证了三维重建增益，
  也不等于完成了 Part A 物理量拟合、真实 I2V 验证或 Part B 裁判校准。

交付原则是完成固定四方法比较并保留失败，而不是通过筛掉困难片段或收紧阈值
追求一个漂亮的“通过”。后续方向应由新增正确坐标、错误接受和覆盖共同决定。

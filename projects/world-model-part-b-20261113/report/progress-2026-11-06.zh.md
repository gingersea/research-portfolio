JSONL 中标定拒绝目前记作 `fit_status: error`，具体原因明确记录为
`unreliable diameter calibration`；它们不是推理崩溃。所有正式视频均

观察到的拒绝原因包括：目标可见帧不足、球/附属细线形成细长分量、表观尺寸
变化、轨迹残差超过 3 px 或 R² 不足。抽样人工检查还见到额外球体、拖线、
球体被画面边界裁切。该检查用于解释管线失败，不作为 Part B 盲评结果。

生成参数：Wan 为 832×480、81 帧、16 fps；CogVideoX 为 720×480、49 帧、
8 fps；均为 50 步、guidance 5.0、种子 0/1/2。分别在 GPU 0/1 上独立运行。
元数据记录的生成累计耗时分别约 35.9 和 39.2 分钟，含加载/编码等开销，
不是精确 GPU 活跃时间。另有一段独立的 Wan 33 帧冒烟视频，不计入 24 段。

合成验证中，自由落体 g 误差 0.054%，抛体 g 误差 0.162%，单摆 T 误差
0.138%，水平初速度误差 3.282%；六项均通过原计划容差。
**这只证明检测器能处理该合成验证域，不能替代真实生成视频上的有效性。**

## 6. 执行决策、代价与已知待办

| 决策 | 原因 | 代价/边界 |
|---|---|---|
| 接续最新视频设计 | 已有设计与工作树明确替代气象方向 | 若方向需恢复，需重新对齐范围；旧文档保留 |
| 以 Tasks 1–6/12 定义半程 | 按可验收交付物而非文件数量计进度 | 不代表工作量/论文进度正好一半 |
| 本次保持未提交状态 | 当前请求未明确要求提交或推送 | 用源代码哈希补充基准 commit 的溯源 |
| 不给未说明的初速度伪造真值 | 提示未指定 2 m/s 等数值 | 水平初速度无相对误差评分 |
| 实际推理与权重由执行器验证 | 独立 reviewer 的 CPU 审查不覆盖 GPU 实验 | 以实测与哈希验收补足，不能只信单测 |
| 后六项留待下个里程碑 | 用户要求到半程停下报告 | 尚无完整 benchmark 或论文结论 |
| 用红色目标分割替代首帧差分 | 所有 Part A 提示指定红球；已复现残影 | 非红目标会被拒绝，方法适用域有限 |
| 拒绝不可靠尺度而非报告精确偏差值 | 模糊合成案例曾把真值 9.8 拟合为 6.25 | 覆盖率降低；拒绝不等于模型违反物理 |
| 镜像分块下载后核对上游哈希 | 当前直接 HF 连接不可用或缓慢 | 增加传输依赖；仅接受上游哈希一致文件 |

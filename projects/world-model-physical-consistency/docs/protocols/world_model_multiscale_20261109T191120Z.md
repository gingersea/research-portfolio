# 多尺度检测器训练对照（运行前固定）

用户要求继续视频物理一致性研究；承接上一轮尺度压力测试的明确下一步。执行位置 projects/world-model-physical-consistency/research/multiscale_20261109T191120Z/。时间戳按UTC；本地日期2026-11-10。

研究问题：固定结构和训练预算下，多尺度合成增强是否改善小目标测量，同时保持负例的误报控制？所有数据均标明程序合成，不制造生成视频人工标签。

设计：TinyUNet 29465参数，2训练臂 single_scale / multiscale，3训练种子7/17/27，共6次从头训练。每臂训练2048幅（1536正例、512负例），验证320幅（256正例、64负例）；训练源seed61001、验证seed62001，增强seed按源seed+100。两臂训练源相同，控制臂维持96×96，增强臂将整幅场景缩为16..96像素方形贴片并随机置于96×96白底，图像INTER_AREA、标签nearest。增强包含物体和背景几何变化，不能将作用完全归因于球体尺寸。

负例由灰背景/噪声和1–2像素红线构成，没有球，标签全空；不从生成视频推断真值。验证集固定混合尺度，供两臂使用相同选择标准。损失沿用BCE+softDice，Adam lr.001，batch64，12epochs，不根据测试结果加训或调阈值；阈值固定.5。选择验证正例IoU×.8+负例无预测比例×.2最高epoch（平局取早期）。记录每epoch、每模型权重哈希。

在6模型全部完成并固定检查点后才评测新测试集：正例256、负例64，源seed63001，不使用旧stress seed40001。将同一场景构造成192×112白底，贴片24/48/96；分别native、warp96、letterbox96。逆变换回192×112计算IoU/非空/质心误差（正例空预测按对角线惩罚）；负例报告任何非空预测的帧级FPR，不计算目标质心或含糊的空掩膜IoU。

基线：旧冻结TinyUNet、颜色阈值；辅助参照，不将训练数据变化归因于单一尺度因子。主要效应：patch24、warp96下multiscale−single_scale的正例IoU差。先在同场景对3个种子取均值，再按256场景配对bootstrap2000次，95%百分位CI，seed20261111；CI条件于这3个已训练模型，不包含完整训练随机性。另报告3个训练种子的效应范围及各条件负例FPR。其余18条件/两类指标均为探索性描述，不做P值/显著性宣称及多重检验。

每个程序场景为抽样单位；同场景的尺度/策略/方法均配对重复，训练种子是优化重复，不是额外独立测试图。记录可重生数据的输入代码哈希、张量哈希、训练配置、软件和设备、检查点、逐场景结果、独立推理重放核验。人工生成视频标签仍空白，不进行新物理排名。产物进入时间戳项目和shared/handoff。
